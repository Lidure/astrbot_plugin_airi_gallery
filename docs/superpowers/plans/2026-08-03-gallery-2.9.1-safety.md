> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make v2.9 local-deletion synchronization prove local/remote byte equality before deleting remote files, fix callable administrator checks, and ship regression tests and consistent help aliases.

**Architecture:** Put deterministic safety decisions in a new AstrBot-independent `gallery_safety.py` module and keep network, filesystem mutation, locking, and chat output in `main.py`. Upgrade the persisted hash index to schema v2 with optional Git blob and verified remote SHAs; legacy entries remain valid for duplicate detection but cannot authorize remote deletion until a sync or push verifies them.

**Tech Stack:** Python 3.10+, standard library (`dataclasses`, `hashlib`, `inspect`, `pathlib`), existing AstrBot APIs, pytest for development tests, GitHub Actions.

## Global Constraints

- Do not add runtime dependencies or configuration fields.
- Preserve existing gallery files, configuration keys, commands, GitHub/Gitee behavior, LLM tools, and Cloud page behavior except for stricter remote-deletion eligibility.
- Keep `use_permission` default `false`; strengthen documentation rather than locking out existing installations.
- Never authorize deletion from file size alone.
- Never expose Git tokens or repository credentials in messages, logs, tests, or fixtures.
- Version all release surfaces as `v2.9.1` only after behavior and tests are complete.

```python
from __future__ import annotations

import hashlib
import inspect


def read_bool_flag(obj: object, attribute: str) -> bool:
    value = getattr(obj, attribute, False)
    if callable(value):
        try:
            value = value()
        except Exception:
            return False
    if inspect.isawaitable(value):
        if inspect.iscoroutine(value):
            value.close()
        return False
    return bool(value)


def git_blob_sha(content: bytes) -> str:
    header = f"blob {len(content)}\0".encode("ascii")
    return hashlib.sha1(header + content).hexdigest()
```

```python
HASH_INDEX_VERSION = 2


def normalize_hash_index(payload: object) -> dict[str, dict[str, object]]:
    if not isinstance(payload, dict):
        return {}
    raw_files = payload.get("files", {})
    if not isinstance(raw_files, dict):
        return {}
    normalized: dict[str, dict[str, object]] = {}
    for path, raw_entry in raw_files.items():
        if not isinstance(raw_entry, dict) or not raw_entry.get("hash"):
            continue
        entry = dict(raw_entry)
        git_sha = str(entry.get("git_blob_sha", "")).strip()
        remote_sha = str(entry.get("remote_sha", "")).strip()
        if git_sha:
            entry["git_blob_sha"] = git_sha
        else:
            entry.pop("git_blob_sha", None)
        if remote_sha:
            entry["remote_sha"] = remote_sha
        else:
            entry.pop("remote_sha", None)
        normalized[str(path)] = entry
    return normalized


def verified_remote_sha(entry: object) -> str | None:
    if not isinstance(entry, dict):
        return None
    git_sha = str(entry.get("git_blob_sha", "")).strip()
    remote_sha = str(entry.get("remote_sha", "")).strip()
    return remote_sha if git_sha and git_sha == remote_sha else None
```

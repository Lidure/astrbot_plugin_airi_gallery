# astrbot_plugin_airi_gallery

AstrBot 数字排序图库插件。

## 文件说明

- `metadata.yaml`: 插件元数据
- `main.py`: 插件入口

## 存储结构

- 图片默认存放在 `data/plugin_data/astrbot_plugin_airi_gallery/gallery/`
- 子文件夹名代表分类，例如 `gallery/表情包/1.png`
- 文件名统一使用数字序号，支持按编号查看和删除

## 命令

- `看命令触发模式`（插件配置）：`no_prefix` 或 `prefix`
- `no_prefix`（默认）：触发方式是 `看<分类>` / `看123`
- `prefix`：触发方式是 `/看<分类>` / `/看123`
- `看<分类>`：从对应分类里随机返回一张图片或表情包
- `看全部<分类>`：输出该分类下全部图片的总览图，并在图片下方标注序号
- `看123`：返回编号为 `123` 的图片或表情包
- `/分类列表`：查看当前已创建的分类
- `/创建<分类>`：创建一个分类文件夹
- `/上传<分类>`：回复一张图片或表情包后执行，保存到对应分类（分类需先创建）
- `/删除123`：删除编号为 `123` 的图片或表情包
- `/导入图库`：重新扫描图库并整理编号

## 说明

- 插件会在启动时自动整理图库中的数字编号
- 如果你手动把图片拖进本地图库目录，启动后也会自动重新编号
